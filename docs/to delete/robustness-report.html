#1
clear / cls crashes on piped stdin
Commands clear and cls threw an unhandled CLR exception (exit -532462766) when stdout was redirected.
AnsiConsole.Clear() throws InvalidOperationException when the console is not an interactive terminal. Five call-sites across Program.cs, Program.EncodeInteraction.cs, and Program.OperationSessions.cs lacked the try-catch guard already used in StartupChecks.cs.
Critical — crash / non-zero exit
✓ Fixed
#2
add (no args) crashes with Spectre markup exception
Running add without arguments in the encode session threw “Could not find color or style 'module/<category>/<id>'”.
The usage-message string [module/<category>/<id> | <global_id>] was passed directly to AnsiConsole.MarkupLine(); square brackets were interpreted as Spectre markup tags. Fix: Markup.Escape() wraps the literal portion.
Critical — crash / non-zero exit
✓ Fixed
