Why Washmachine?

Other tools make you choose between flexibility and power. Washmachine gives you both — wrapped in a single, opinionated workflow that just works.

🔄 Adapt, Don't Rewrite

When a technique gets flagged, update the YAML playbook. No code changes, no recompilation. Hand it to an LLM if you want — the playbook is all you need.

🏗️ One Tool, Full Pipeline

From raw shellcode to encoded loader to backdoored PE — the entire offensive workflow lives under one roof. No juggling between five different tools.

⌨️ CLI-First, GUI-Ready

Every feature works headlessly through the CLI for automation and scripting. Prefer a visual workflow? The WinUI 3 desktop app has you covered with the exact same capabilities.

🌍 Community-Extensible

Custom templates, custom snippets, custom sections — all through YAML. Share your playbooks, import others'. The ecosystem grows without touching C#.

See It in Action

Four commands that show the breadth of what Washmachine can do.

# Build a loader with guardrails — domain-locked execution
washmachine-cli encode -s payload.bin -t default --snippet guardrails=domain_check

# Backdoor a PE via TLS callback — runs before main(), pre-entry stealth
washmachine-cli backdoor --pe target.exe -s payload.bin -m tls-callback

# Deep-dive PE analysis with structured JSON output
washmachine-cli analyze target.exe --json

# Browse all 89 available snippets across 10 categories
washmachine-cli list --snippets
