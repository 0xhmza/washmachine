// BUILDING & DEPLOYMENT

Complete build and publishing guide

// REQUIREMENTS

CLI (washmachine-cli)

OS Windows 10 1809 (build 17763)+ / Windows 11
.NET 8.0 Runtime x64
C++ Compiler MSVC / MinGW-w64 g++ / clang++ on PATH
Python 3.10+ on PATH (for Bin2Shell encoding)

Desktop App (washmachine)

OS Windows 10 1809 (build 17763)+ / Windows 11
.NET 8.0 Desktop Runtime x64
Windows App SDK 1.8 Runtime
C++ Compiler MSVC / MinGW-w64 g++ / clang++ on PATH
Python 3.10+ on PATH (for Bin2Shell encoding)

// PUBLISHING (RELEASE)

CLI — Single-File Executable

# Publish CLI as single-file exe
PS> dotnet publish Washmachine.Cli\Washmachine.Cli.csproj -c Release

Output: Output\cli\Release\publish\washmachine-cli.exe

Framework-dependent single executable

End-users need: .NET 8 Runtime x64

NOT the full Desktop Runtime

GUI — Framework-Dependent WinExe

# Publish GUI app
PS> dotnet publish washmachine.csproj -c Release

Output: Output\Release\publish\washmachine.exe
        + supporting DLLs

Framework-dependent application

End-users need:

  • .NET 8 Desktop Runtime x64
  • Windows App SDK 1.8 Runtime

// END-PRODUCT DELIVERY

Two separately distributable products come out of the same repo:

1. CLI Tool (washmachine-cli)

Minimum required files from Output\cli\Release\publish\:

washmachine-cli/
├── washmachine-cli.exe         ← Single-file executable
└── Assets/
    └── vx_api_snippets.yaml    ← YAML catalog (required at runtime)
📦

Bin2Shell is downloaded automatically on first use of encoding features (washmachine-cli provision).

Runtime prerequisite: .NET 8 Runtime x64

2. GUI Desktop App (washmachine)

Files from Output\Release\publish\:

washmachine/
├── washmachine.exe
├── washmachine.dll
├── Assets/
│   └── vx_api_snippets.yaml
└── (supporting .dll files from dotnet publish)

Runtime prerequisites:

  • .NET 8 Desktop Runtime x64
  • Windows App SDK 1.8 Runtime
⚠️

Shared Runtime Assets

Both products rely on Assets/vx_api_snippets.yaml being present next to the executable (resolved via AppPaths.AssetsDirectory). Always include the Assets/ folder alongside the binary.

// BIN2SHELL AUTO-PROVISIONING

Bin2Shell is expected at Tools\Bin2Shell\main.py relative to the executable.

Automatic Download

Downloaded automatically when:

  • Running washmachine-cli provision
  • Launching the GUI for the first time
PS> washmachine-cli provision

[+] Downloading Bin2Shell...
[████████████████] 100%
[+] Extracting to Tools/Bin2Shell/
[✓] Bin2Shell ready

Manual Installation

Alternatively, place Bin2Shell manually:

washmachine-cli.exe
Tools/
└── Bin2Shell/
    ├── main.py
    ├── algos.yaml
    └── ...

Must be in Tools/Bin2Shell/ subdirectory

// TESTING

Run via PowerShell Driver

# Builds CLI if needed, then runs all phases
PS> .\Testing\run_tests.ps1 -ShellcodeFile path\to\messagebox.bin

# Run only Phase 1 (encoder × envelope combinations)
PS> .\Testing\run_tests.ps1 -Phase 1 -ShellcodeFile path\to\messagebox.bin

# Run only Phase 3 (multiple shellcode inputs from test assets)
PS> .\Testing\run_tests.ps1 -Phase 3

Run Directly via CLI

PS> washmachine-cli test --shellcode path\to\messagebox.bin --phase all
PS> washmachine-cli test --shellcode path\to\messagebox.bin --phase 1 --url http://host/payload.bin
PS> washmachine-cli test --phase 3 --test-assets "testing assets\binary\shellcodes"

Results are written to test_results.json in the CLI executable's directory.

Test Phases

PHASE WHAT IT TESTS
1 All encoder × envelope × web-helper combinations (requires shellcode + optional URL)
2 All template × snippet permutations with default (0) encoding
3 Multiple shellcode inputs from the test assets directory

// TROUBLESHOOTING

Compiler Not Found

[!] No compiler detected

Solution:

  • Install Visual Studio Build Tools (MSVC)
  • Or install MinGW-w64 (GCC)
  • Or install LLVM (Clang)
  • Ensure compiler is on PATH

Bin2Shell Missing

[!] Bin2Shell not found

Solution:

  • Run washmachine-cli provision
  • Or launch GUI (auto-provisions)
  • Ensure Python 3.10+ is on PATH

YAML Catalog Not Found

[!] vx_api_snippets.yaml not found

Solution:

  • Ensure Assets/ folder is next to exe
  • Check vx_api_snippets.yaml exists
  • Verify file permissions

WinUI App Won't Launch

Application failed to start

Solution:

  • Install .NET 8 Desktop Runtime x64
  • Install Windows App SDK 1.8 Runtime
  • Windows 10 1809+ or Windows 11 required
