WASHMACHINE

CLI-first shellcode loader builder with WinUI 3 desktop app

Driven entirely by a single YAML catalog. Pick a shellcode source, choose a C++ template, stack pluggable features, and compile.

// CORE CAPABILITIES

01

Multiple Shellcode Sources

  • File (.bin)
  • Raw hex paste
  • URL (web delivery)
  • Built-in test payload
02

YAML Template Engine

  • Single file defines all templates
  • No recompile needed
  • Pluggable snippet sections
  • Custom placeholders
03

Auto-Discovered Compiler

  • MSVC (cl.exe)
  • GCC (g++.exe)
  • Clang (clang++.exe)
  • PATH + VS install detection
04

Payload Encoding

  • Bin2Shell integration
  • Encoder selection (XOR, RC4, AES)
  • Envelope wrapping (Base64, Base32)
  • Anti-emulation options
05

Feature Snippets

  • Anti-debugging checks
  • Environment guardrails
  • Process injection
  • UAC bypass techniques
06

Session Logging

  • Source code preservation
  • Build log capture
  • Timestamped sessions
  • UUID-based tracking

// AVAILABLE COMMANDS

compile
Build a shellcode loader executable
analyze
Analyze a PE file (headers, sections, imports, code caves)
backdoor
Inject shellcode into an existing PE via code-cave
list
List available templates, encoders, snippets, or compilers
provision
Download and install required external tools (Bin2Shell)
test
Run the automated test harness

Shared Core Logic

All business logic lives in Washmachine.Core - a platform-neutral library with no UI dependencies. Both CLI and GUI are thin consumers.

Dual Interface

Access the same features through either a powerful CLI for automation and scripting, or a rich WinUI 3 desktop app for visual workflow.
