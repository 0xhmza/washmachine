// SHELLCODE SOURCES

MODE DESCRIPTION USE CASE
FILE Browse to a .bin shellcode file Pre-generated shellcode from msfvenom, Donut, etc.
RAW Paste raw hex bytes directly (e.g., \xfc\x48\x83...) Quick testing with small payloads
URL Enter remote URL where payload is hosted Web delivery / remote payload fetch
TEST Built-in calc.exe shellcode Smoke-testing the compilation pipeline

// WEB PAYLOAD WIZARD

Step-by-Step Configuration

When URL mode is selected, the Web Payload Wizard guides you through:

  • Choose encoder (XOR, RC4, AES, etc.)
  • Select envelope (Base64, Base32, Base91)
  • Pick web-fetch helper method
  • Enter hosting URL

Automatic Integration

The wizard:

  • Calls Bin2Shell in -w mode
  • Verifies the endpoint responds
  • Generates C++ fetch + decode code
  • Stitches it into the template automatically

Template Selection

// SNIPPET SECTIONS

Each template placeholder of kind: snippet maps to one section in the catalog.

🛡️ Anti-Debugging

Section: antidebugging | Multiple: Yes

Stack multiple anti-debugging checks:

  • IsDebuggerPresent
  • CloseHandle invalid address
  • CheckRemoteDebuggerPresent
  • NtQueryInformationProcess

🎯 Process Injection

Section: psinjection | Multiple: No

Choose one injection technique:

  • WriteProcessMemory + CreateRemoteThread
  • QueueUserAPC injection
  • Process hollowing
  • Thread hijacking

⚡ Shellcode Execution

Section: shellcodeexecution | Multiple: No

Execution method:

  • VirtualAlloc + function pointer
  • CreateThread
  • NtMapViewOfSection
  • Fibers

🔒 Guardrails

Section: guardrail | Multiple: No

Environment restrictions:

  • Domain check
  • Username validation
  • Environment variable
  • Hostname verification

🚀 UAC Bypass

Section: uacb | Multiple: No

Privilege escalation techniques:

  • Fodhelper method
  • ComputerDefaults bypass
  • Sdclt method
  • Token manipulation

🎭 Evasion Techniques

Section: evasion | Multiple: Yes

Sandbox & analysis evasion:

  • Sleep obfuscation
  • VM detection
  • Sandbox checks
  • API unhooking
⚠️

Multiple Selection

Sections with allowMultiple: true let you stack several snippets. Others allow only one choice.

// ENCODING OPTIONS

Encoder

Transform raw shellcode bytes:

  • XOR (single/multi-byte)
  • RC4
  • AES-128/256
  • ChaCha20
  • Custom algorithms

Envelope

Wrap encoded payload:

  • Base64
  • Base32
  • Base91
  • Hex encoding
  • Custom wrappers

Anti-Emulation

Sandbox detection:

  • API call patterns
  • Timing checks
  • Resource exhaustion
  • Environment fingerprinting

// AUTO-PROVISIONING

Automatic Tool Download

Washmachine downloads Bin2Shell automatically on first run if not present.

> washmachine-cli provision
[+] Downloading Bin2Shell...
[+] Extracting to Tools/Bin2Shell/
[✓] Bin2Shell ready

Session Logging

Each compilation saves complete session artifacts:

  • source.cpp - Generated C++ code
  • build_log.txt - Compiler output
  • Timestamped directory structure
  • UUID-based unique identifiers
